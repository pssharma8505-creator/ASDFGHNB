# Industrial Automation & Engineering Portfolio

Full-stack responsive portfolio and showcase for industrial automation, engineering consultancy, PLC/SCADA architecture, and control panels.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Add your `GEMINI_API_KEY` in `.env` if using AI consulting features.

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
```

### 5. Start Production Server
```bash
npm start
```

## 📁 Repository Overview
- `src/` — React frontend application with Tailwind CSS and Framer Motion
- `server.ts` — Express backend with Gemini AI integration and inquiry API
- `public/` — Static assets, company profile catalog, robots.txt, and sitemaps
- `metadata.json` — AI Studio application metadata
